## Brand & Style

The brand identity balances clinical precision with approachable everyday vitality. The design system embodies a modern health-tech aesthetic: calm, scientifically credible, transparent, and motivating without relying on aggressive gym tropes or juvenile gamification. 

Visual attributes:
- **Clean Modern Wellness**: Generous negative space, crisp typography, and luminous natural greens that communicate vitality, nourishment, and metabolic balance.
- **Intelligent Simplicity**: Complex nutritional data (macros, micronutrients, caloric burns, AI vision confidence scores) is distilled into intuitive circular arcs, proportional micro-bars, and scannable visual chunks.
- **Tactile Softness & Precision**: Smooth 16px–24px radiuses paired with hairline borders (`#E2E8F0`) and diffused emerald-tinted ambient elevation give cards an airy, floating sensation.
- **Language & Tone**: Clear, encouraging, and functional Turkish terminology ("Bugün", "Öğün Ekle", "Aktivite", "Makro Dengesi", "Yapay Zeka Analizi").

## Typography

Plus Jakarta Sans provides high geometric clarity, open apertures, and warm, rounded terminals ideal for mobile wellness interfaces. 

Rules:
- All numeric measurements (calories, grams, milliliters, burn rates) must use `font-variant-numeric: tabular-nums` to ensure stability when values update live.
- Calorie counts and macro values pair a heavy weight (`font-weight: 700` or `800`) with a lighter muted unit indicator (`kcal`, `g`, `ml`) set at `body-sm` in `#64748B`.
- Headings maintain tight letter-spacing (`-0.015em` to `-0.03em`) for a polished modern consumer feel.
- Turkish character sets (ş, ğ, ı, İ, ç, ö, ü) render consistently without clipping diacritics under the specified line-height multiples.

## Layout & Spacing

A mobile-first fluid layout optimized for single-hand viewport ergonomics:

- **App Shell Constraint**: Mobile viewport defaults to max-width `440px` centered on larger displays, providing native app simulation on mobile web.
- **Safe Margins**:
  - Horizontal screen gutters: `16px` (`space-md`) on mobile screens under 400px; `20px` (`space-lg`) on 400px–600px.
  - Bottom padding offset: Safe-area inset + `5.5rem` (`88px`) to ensure scrollable lists never hide under the floating bottom navigation bar.
- **Vertical Rhythm**:
  - Card inner padding: `16px` standard, `20px` for hero macro overview containers.
  - Item stack gaps: `12px` between food list entries; `16px` between structural card sections.
- **Touch Target Enforcements**:
  - Every interactive button, pill chip, and icon trigger guarantees a minimal hit zone of `44px x 44px` (`touch-min`).

## Elevation & Depth

Visual hierarchy uses clean multi-stop ambient shadows layered over crisp borders rather than dense drop shadows:

- **Level 0 (Canvas)**: `#F8FAFC` flat base background.
- **Level 1 (Card Surface)**: `#FFFFFF` surface with `1px solid #E2E8F0` and subtle ambient diffusion:
  `box-shadow: 0 1px 3px 0 rgba(15, 23, 42, 0.04), 0 4px 12px -2px rgba(15, 23, 42, 0.03);`
- **Level 2 (Interactive Floating / Active Cards)**:
  `box-shadow: 0 4px 6px -1px rgba(5, 150, 105, 0.06), 0 10px 24px -4px rgba(15, 23, 42, 0.06); border-color: #CBD5E1;`
- **Level 3 (Elevated Center CTA & Modals)**:
  Center '+ Öğün Ekle' action and bottom sheet modals use an emerald ambient glow:
  `box-shadow: 0 10px 25px -3px rgba(5, 150, 105, 0.35), 0 4px 10px -2px rgba(5, 150, 105, 0.2);`
- **Backdrop Blur Layers**: Navigation bar and sticky top header use `rgba(255, 255, 255, 0.88)` with `backdrop-filter: blur(12px)` and a subtle `border-b: 1px solid rgba(226, 232, 240, 0.8)`.

## Shapes

The interface utilizes a soft, organic geometric curvature (`level 2` roundedness):

- **Primary Cards**: `rounded-2xl` (`16px`) for sub-cards and meal list entries; `rounded-3xl` (`24px`) for the primary daily summary dashboard container.
- **Interactive Action Pills & Badges**: Fully rounded (`rounded-full` / `9999px`) for macro indicators, confidence tags, filters, and quick-add tokens.
- **Input Fields & Search**: `rounded-xl` (`12px`) with recessed internal paddings.
- **Floating Action Button**: Perfectly circular (`56px x 56px`, `rounded-full`) positioned centrally within the bottom navigation shelf.
- **Progress Trackers**: Micro-bars use full pill endcaps (`rx="999"`) on all SVG path caps for liquid, continuous visual flow.
